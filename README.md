# TERRACE BLOOM 梯田復甦

第一人稱的山坡梯田修復遊戲。清除雜草碎石、補回崩塌的石牆、鋪竹管與開水閘把山泉一層層引下來——有水的梯田會轉綠、作物隨時間成熟，青蛙、鳥群、螢火蟲陸續回到山谷。修復度達 100% 時迎來燈籠祭；第 12 天結束前沒完成則收穫季已過。

- 線上遊玩：https://akkuo.github.io/terrace-bloom/
- 單一 `index.html`，Three.js r170（CDN importmap），零外部素材：所有模型、貼圖、音效與音樂都由程式產生。

## 操作

| 按鍵 | 功能 |
|---|---|
| `W` `A` `S` `D` / 方向鍵 | 移動 |
| 滑鼠 | 視角（點畫面進入 Pointer Lock；鎖定失敗時自動改為按住左鍵拖曳） |
| 左鍵 | 使用工具（雜草、碎石要長按；對準目標時會自動切換到合適的工具） |
| `E` | 互動：撿石塊、砍竹管、開關水閘 |
| `1`–`4` | 鋤頭／石塊／竹管／種子 |
| `Space` / `Shift` | 跳 / 跑 |
| `P` / `Esc` | 暫停 |
| `M` | 靜音 |

觸控：左半邊浮動搖桿移動（推到底會跑）、右半邊拖曳視角，右下「使用」「E」「跳」「工具」按鈕。

## 玩法：水怎麼流

1. 山泉台地（最上方）鋪好兩段竹管 → 第 5 層梯田有水。
2. 某層的擋土牆缺口全部補滿 3 顆石塊，那層才蓄得住水（否則水會從缺口漏掉）。
3. 打開那層前緣的水閘，並在水閘下方鋪竹管 → 水流到下一層。
4. 清完某層的雜草碎石才能在那層苗床播種；蓄水的梯田上作物才會生長，雨天生長加快。

修復度 = 雜草 20% + 石牆 20% + 竹管 12% + 蓄水 18% + 作物生長 30%。

## 技術重點

- 第一人稱鏡頭以 `rotation.order = 'YXZ'` 直接組 yaw/pitch，不使用 `lookAt`。
- 地形高度由函式 `groundH()` 解析計算（梯田平台 + 斜坡），移動時以前方探針做台階／牆面碰撞。
- 石牆約 700 顆石塊用單一 `InstancedMesh`；缺口石塊以縮放 0 隱藏、補石時逐步顯示。
- 日夜循環（自寫天空球 shader、星空、日月光源）、隨機雨天（LineSegments 雨絲、霧距縮短、合成雨聲）。
- Web Audio 合成：五聲音階背景樂、挖掘、石塊、竹管、水閘、蛙鳴、鳥叫、祭典琶音。
- 偵測輸入法組字（`isComposing` / `Process` / `keyCode 229` / `compositionstart`）時提示切換英文輸入。
- 測試介面：`window.__debug()`、`window.__start()`、`?autostart=1`；另有驗證用 `__tp()`、`__time()`、`__items()`、`__complete()`。
